# Root-supplied two-orientation mixture corollary: confirmed

After freezing the independent base derivation, root supplied this extension. Let mu+ and mu- be the two diagonal-class plane laws, and nu=t mu+ +(1-t)mu- for any fixed0<=t<=1. For the event B that all eight neighbors of0 carry c, both laws have the same positive conditional vector q_c(s) proportional K(s,c)^4/(K²(s,c))². This does not require equal probabilities of B: nu(X0=s,B)=q_c(s)[t mu+(B)+(1-t)mu-(B)], and the bracket is positive. Hence the mixture has the same conditional on B. For a positive nonconstant triple it fails the original four-NN static specification by the same tower argument. No posterior orientation calculation on the entire exterior is needed.

The equal mixture is invariant under the spatial square-dihedral group: every group element either preserves both diagonal classes or exchanges them, as is seen from the finite rectangle products, and uniqueness of each cylinder extension transfers the identity to the plane. Translations preserve both classes as well. This does not show that the mixture has either single-class six-neighbor specification; it need not. Nor does it rule out arbitrary other order families or laws. It establishes only that convex mixing of these two supplied orientation laws cannot restore the original nearest-neighbor static conditional.
