# Exact target contract

## Finite carrier

Let `C` be the cyclic shift on `C^3`, `omega=exp(2 pi i/3)`, and

```text
P_r = (1/3) sum_(k=0)^2 omega^(-r k) C^k,
P_s = P_0,
P_d = P_1 + P_2.
```

Complex conjugation `K` fixes `P_s` and swaps `P_1,P_2`.  Classify every
Hermitian `C3`-equivariant operator, every `K`-even member, and every
`K`-even projection.  Test the positive candidate:

> a nonzero `K`-even projection which vanishes on the singlet is uniquely
> `P_d`.

This fixes a source projector inside the supplied finite carrier only.  It
does not identify that carrier or projector as physical.

## Source/action response

For a positive `K`-even invariant quadratic action

```text
A = a_s P_s + a_d P_d,
```

and invariant source `O`, define the formal determinant and the stipulated
campaign-normalized finite response

```text
D_A(j) = det(A + j O),
h_A(O) = (1/|C3|) tau(A^-1 O),
tau(X) = Tr(X)/3.
```

Equivalently `h_A(O)=Tr(A^-1 O)/9`.  For `O=P_d`, verify

```text
h_A(P_d) = 2/(9 a_d),
Phi_A = 3 h_A = 2/(3 a_d).
```

The target values occur at `a_d=1`.  The campaign must test whether current
symmetry, positivity, determinant normalization, trace normalization,
projector idempotence, and current premise content force that member.  It must
run the hostile controls `O -> c O` and `a_d -> lambda a_d`.

The leading `1/|C3|` is a stipulated orbit-density factor, not a group
conjugation average.  A true conjugation average of invariant `A^-1 O`
returns the operator unchanged.  `D_A` is a formal finite determinant, not a
physical partition function until the carrier, measure, statistics, action,
and source units are constructed.  The runner must distinguish real-boson,
complex-boson, and Grassmann determinant powers.

## Local/global `C_p` discriminator

For integer `p>=2`, compute exactly

```text
F_p = (1/p) sum_(k=1)^(p-1)
      1 / ((zeta_p^k-1)(zeta_p^(-k)-1))
    = (p^2-1)/(12p),

E_p = (1/p) sum_(k=1)^(p-1) cot(pi k/p)^2
    = (p-1)(p-2)/(3p),
```

where `F_p` is the local cyclic fixed-point density and `E_p` is the magnitude
of the **raw** odd-signature eta invariant of `L(p,1)` under an explicitly
stated quotient action, round metric, orientation, and APS operator
convention.  Verify

```text
F_3 = E_3 = 2/9,
E_p-F_p = (p-1)(p-3)/(4p),
```

so `p=3` is the unique nontrivial integer equality.  Keep the two objects
typed separately: numerical equality is not a physical carrier theorem.
Also verify that weights `(1,1)` and `(1,-1)` reverse the cotangent-product
sign, and that `h_B=1` gives reduced eta `11/18` or `7/18`, not `2/9`.

## Differential-character type repair

A flat loop holonomy on a torsion generator `g` of order `p` is a character
`chi: Z_p -> R/Z`, hence `p chi(g)=0 mod 1` and

```text
chi(g) in {m/p mod 1 : m=0,...,p-1}.
```

At `p=3`, `2/9` is not in this set.  Check the exact prior-art source lines
that both state `3*(2/9)=2/3 != 0 mod 1` and nevertheless call the same value
a valid flat holonomy.  The campaign may correct only the bounded route:
the global eta invariant is not thereby a flat character on the `Z3`
generator.  It must not claim that eta invariants or differential cohomology
can never enter another construction.
