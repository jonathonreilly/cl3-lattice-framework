# Exact target contract

## Frozen finite objects

Use `A = M_2(C)`, the Pauli matrices, exact rank-one projectors

```text
Pz+ = (I+Z)/2,  Pz- = (I-Z)/2,
Px+ = (I+X)/2,  Px- = (I-X)/2,
```

and finite Gibbs packages whose exponentials reduce exactly to diagonal
rational weights. All equality checks must be exact; floating-point evidence
cannot establish the theorem.

## Required certificates

1. **Source binding and novelty.** Pin current main, current minimal axioms, the
   closest August Admissibility/effect carrier results, the June/July Record
   instrument results, `I-4`, Block 47, and open PR heads `#7828-#7832`.
2. **Action-to-functional positive collapse.** For a fully specified finite
   `(H,beta,normalization)` package, construct `rho_H`, certify positivity and
   unit trace, and certify uniqueness of `omega_H(E)=Tr(rho_H E)` within that
   semantics. Separately exhibit that bare `H` without a preparation/state
   rule admits multiple normalized positive functionals.
3. **Event nonselection.** On one fixed nonmaximally mixed `rho`, compare the
   `Z` and `X` PVMs. Both are valid resolutions of identity and yield different
   exact distributions. No basis may be called physically selected by `rho`.
4. **Type/quotient boundary.** Exhibit distinct probability measures over
   one-site density matrices with the same barycenter and hence identical
   values on every effect. This proves that state-object distributions and
   effect functionals are not the same object and that the barycenter map is
   non-injective.
5. **Born normalization conditional on registration.** For every frozen PVM,
   prove nonnegative weights summing to one under `omega_H`. Treat this as a
   theorem conditional on an event registration, not a derivation that the
   Admissibility distribution equals those weights.
6. **Instrument/content nonselection.** Construct CP outcome maps with the same
   effects/traces but different normalized output contents. Identify exactly
   which matching-output premise reduces a rank-one PVM branch to the Lüders
   writer, consistent with PR `#7831` rather than duplicating it.
7. **Admissibility-law independence.** Give two fixed, cubic-covariant,
   nearest-neighbor-varying probability laws compatible with the literal
   Admissibility clause and the same frozen action package. They must disagree
   for at least one neighbor condition. This certificate is killed if a current
   retained source supplies the equality to the action functional.
8. **Formation independence.** Give two processes with the same conditional
   Record-content distribution but different formation hazard/rate or site
   allocation. Only Records are treated as read data.
9. **Permanence implementation boundary.** Show that an active Hamiltonian not
   commuting with a Record projector changes that projector, while a gated or
   separate pointer can preserve it. Record permanence is an axiom requirement,
   not an automatically selected implementation.
10. **Commuting triangle.** State sufficient typed premises under which action,
    registered effects, an instrument, and Record labels agree end to end.
    Mark every premise as derived, supplied, axiom content, or open.
11. **Axiom decision surface.** If current wording does not close the triangle,
    provide minimal exact owner options: semantic clarification only, a new
    physical identification clause, or leave the bridge conditional. Do not
    modify `MINIMAL_AXIOMS_2026-06-29.md`.
12. **No-go discipline.** Any bounded negative must include N1--N8, with N5
    rhetoric checks emitted in cached stdout. The negative scope is limited to
    entailment by the current axioms, not possibility of a future physical
    model.
13. **Resolution and mutation.** Emit substantive `per_element:`, `per_site:`,
    `per_mode:`, `per_block:`, and `lattice_wide:` lines; kill every registered
    mutation exactly once; terminate with `TOTAL: PASS=N FAIL=0`.
14. **Impact honesty.** No TOE movement unless an existing obligation is
    actually retired. Conditional exact mathematics and issue localization are
    reported separately.

## Hard kills

Kill the block for conflating density matrices, algebra elements, effects,
outcomes, and Records; calling a supplied measurement registration derived;
claiming direct observation of unrecorded alternatives; smuggling formation
hazard into a conditional distribution; treating an action Hamiltonian alone
as a state; reusing an unaudited note as retained authority; or wording a broad
measurement/Born/Record no-go.
