# Five-Physicist Panel Return

The pre-Block-08 panel ranked the frozen H2 discriminator first, physical M4
distribution second, generated history third, rate/clock fourth, and q=4
gravity fifth.  Block 08 follows the discriminator's result and localizes the
earliest missing object to a second physically owned free condition orbit.

The post-result five-physicist rerank is:

1. quantum-owned direction/corner quadrupole;
2. state-dependent M4, only if its input is strictly causal-past and
   source-independent;
3. a physically compatible and dynamically reachable two-cell condition;
4. generated history/rate/clock after source ownership;
5. an invariant seventh bit only after a physical owner is derived;
6. q=4 gravity as a small parallel hedge tied to source/time.

The winning reason is structural rather than a vote: the trace-free symmetric
square of a local vector is exactly `E direct-sum T2`, the Block-08 common
module.  A fixed radius-one construction can combine axis weights from the
six neighboring M2 algebras with composite corner correlations in their tensor
product into one symmetric trace-free tensor.  This directly tests whether
local quantum conditions own the missing source coordinates without importing
an H1/H2 label.

The panel rejected three tempting shortcuts.  A bare seventh bit only names
the missing sector.  The unrestricted two-mask product has 132 free 24-orbits,
so capacity alone is nearly vacuous until locality and reachability select a
physical subset.  The existing effective M4 state is downstream of the
source-dependent C32 state unless a strictly earlier preparation is supplied,
making it circular as a source selector.

Block 09 should freeze one cubic-covariant positive local preparation from
causal-past data, one normalization, and one degree-bounded quadrupole map.  It
must then test positivity/completeness, 24/24 cubic covariance, translation
covariance, strict radius one, exact H1 and H2 target orbits, native forward
and literal-reverse sources, and a held-out H3/H4 family or symbolic open
family.  Outcomes are `OWNED-COMMON`, `CAPACITY-ONLY`, or `NO-MEMBER`; solving
weights backward from a target or consuming a downstream M4 state forces
`CAPACITY-ONLY`.

No panel member recommended an axiom update.  Qubit plus Admissibility already
permit a fixed neighbor-M2-dependent distribution; the missing object is its
extensional physical law.
