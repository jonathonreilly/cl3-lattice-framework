gains, irreducible ranks, covariance, handedness, moment leakage, source gain,
H1/H2 positivity, incoming/outgoing decode, actual reverse, native sources,
open-family extent, runtime labels, and scope inflation.

discipline, rank/decode defects, covariance/law defects, H1/H2 decode,
positivity and reverse defects, open-family failures, and false downstream

cached only inside each process.  A mutation is rejected only when at least one
scorecard gate fails.
