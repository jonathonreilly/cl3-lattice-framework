# Record formation, transport and an actual common energy apparatus

The owner authorized a 12-hour campaign on 2026-09-07. The first target is
whether the fixed five-event matter transport fixture of PR 7996 remains
viable under the actual shared apparatus of PR 7983. Later blocks address
formation selection and renewal or the next independently valuable frontier.

## Exact first-block contract

- Domain: the open eight-vertex cube, twelve signed bonds, fixed N=4 sector,
  native nonbridge edge Records, and the exact existing phase pulse, path and
  five dwells. Both parent notes and sources are pinned in STATE.yaml.
- Allowed premises: all supplied carrier, code, Hamiltonian, preparation,
  Born/Lueders and scheduling definitions are explicit conditional inputs.
  The shared positive-energy apparatus is the parent construction, evaluated
  on the actual nonstationary initial state with correlations retained.
- Primary battery: normalized sine packet on [24,25], width w=t=1, with
  parent bound B=tL=12 and physical energy domain [0,49]. Its mean is 24.5.
  The old scalar reserve 4/cap8 is a comparator, not the apparatus resource.
- Frozen protocol: edges (0,3,5,6,9), pulse exp[-i*0.7*(n0-n1)], dwells
  (0.41,0.37,0.29,0.23,0.19). No outcome-dependent reset or protocol retuning.
- Required observations: actual pre-event and post-event reduced states,
  all site densities and surviving-bond currents, fixed number, branch
  weights, persistent Record outputs, graph connectivity, physical battery
  energy/cap, and actual total-energy conservation at every prefix.
- Original transport comparator: current threshold 0.02 with at least four
  live edges, plus the original density interval and front-current criterion.
  Record failure honestly; scientific acceptance is distinct from numerical
  implementation validation. Add post-event measurements explicitly rather
  than treating the parent's pre-deletion measurements as post-event data.
- Completion witness: independent implementations or representation checks,
  controlled numerical error, exact operator arguments for conservation and
  persistence, a note stating the narrow result, source-pinned outputs,
  independent review and a branch PR. A failed transport test is a valid
  result at its measured scope.
- Not closure: scalar bookkeeping alone; assuming initial stationarity;
  replacing the battery by a fresh packet between events; fitting the pulse,
  dwell or packet width until transport passes; claiming autonomous formation
  or a nearest-neighbor physical apparatus from the spectral lift alone.

Battery width variants, if needed, must be preregistered separately after the
baseline and reported as explicit coherence-resource costs, never replacements
for the baseline result.
