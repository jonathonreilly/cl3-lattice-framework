# Prospective finite-boundary padding check

Analytical padding idea derived after the main contract and before finite geometry enumeration. Theorem1 permits site-dependent perturbations with a common range and uniform norm bound. For each finite ordinary open cubic graph, embed every physical link into full outgoing-link cells; add enough cells to contain x+Lambda0 for every retained plaquette anchor. Define phi_x^(graph) by the actual retained plaquettes only, extended by zero for other anchors. Extra links remain exactly decoupled electric factors. Test the exact factorization on fixed vertex boxes {0,...,L}^3 for L=1,2 and padded cell boxes {0,...,L+1}^3. This is a finite-volume use of the theorem with graph-dependent interactions, not an application of its thermodynamic-limit assertion to a varying interaction family. No numeric stability constant is introduced.
