# Reuse Map

The primary imports the pinned Block-13 primary only for the unchanged
84-content code, hybrid carrier, fourteen-way probability law, and all-or-none
guard.  It implements the fixed half-space decoder, content-oriented
eligibility, whole-frontier blocked census, composed adjudication, and scope
checks locally.

The independent checker must import neither the Block-14 nor Block-13 primary.
It must rebuild direction extraction, integer lattice geometry, trail and
blocked frontiers, controller identities, and normalization through a
structurally different route and a longer trail range.

Shared exact rational arithmetic, proper-cubic rotations, and immutable signed
coordinate directions are mathematical infrastructure, not shared Block-14
adjudication logic.
