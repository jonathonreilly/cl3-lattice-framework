### Reading of "support condition", refereed

The abelian companion's referee settled what the phrase must mean, and that reading is what item 2 is checked against. `G_v = 0` counts as a support condition
because it is a linear relation among one corner's record values, so that with the corner's other records present the value that would unbalance it carries zero odds
where the last one forms: a zero of the law-level odds **at a site**, in any formation order, with the joint restriction its consequence. Two things have to be true
for that mechanism to have content -- the condition must be a condition on record values, and the set of patterns it allows must be nonempty.

Here the second fails outright, and it fails first. With zero Gauss-invariant record patterns there is nothing at any corner for a site-level zero of the odds to
force **towards**: no formation order of any corner's records reaches an admissible configuration, so the mechanism the abelian result rests on has no content on
this block. The first fails too, and fails in a way no change of frame repairs: item 5's Schmidt rank `2` is basis-free, so the corner condition is a condition on
record values in no single-site product basis at all. This is the exact finite statement, and it is the whole of it: **on this plaquette the non-abelian Gauss law
has no record-pattern solutions.**

**Reading, not theorem.** The abelian law asks each corner for a sum of record values to balance. The non-abelian law asks each corner for something a list of values
cannot say: the matter and the flux meeting there must combine into a single colourless state, and the one state that does is a two-way superposition of two colour
records. A pattern of records has no way to be that.
