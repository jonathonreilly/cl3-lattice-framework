# Normalization and model dictionary

| Object | Normalization and meaning |
|---|---|
| Wilson coefficient c_p | Character coefficient of exp(beta ReTr/3). |
| Physical central convolution | Eigenvalue c_p/(d_p c0), d_p=H(p+rho); no beta^-3/2 multiplier. |
| Supplied central-character sandwich | e^-beta Tconv=Pbeta M_(c_p/(d_p c0)) Pbeta. |
| Its continuum | G0=S M_exp(-Q) S; spectrum-equivalent sqrt(w) exp(L) sqrt(w). |
| Native coefficient model | H-weighted continuum S M_(H exp(-Q)) S; different normalization and spectrum. |
| Full spatial model | A separate multi-link source/environment compression; not identified by this package. |

Pbeta=exp[(beta/2)(J-I)], S=exp(L/2), Q=x²+xy+y², H=xy(x+y)/2. The exact Schur normalization is an older imported identity. The new theorem closes its wall-uniform asymptotic estimate, not the separate spatial/environment identification. The Gaussian ratio is a ratio of two simple sandwich branches, not a physical mass gap.
