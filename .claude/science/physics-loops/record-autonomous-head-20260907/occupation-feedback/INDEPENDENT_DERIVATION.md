For bounded-degree native placement, the unlifted J uses the same endpoint-star edge-qubit neighborhood as hopping/current; K additionally acts on e. ## Exact monomial path formulas and a definite pre-surface option

The preceding resolvent does not require a generic matrix solver. Fix a directed edge path p=(e_1,...,e_j) and let f_l(x) be the occupation configuration after its first l hops starting from x. Define chi_p(x)=1 if every selected hop is active on that configuration, and zero otherwise. Each directed CAR hop is a signed partial permutation, so an active path has a real fermion sign epsilon_p(x)=+/-1 and is injective on its active domain. Put r_l(x)=M_{s_{l-1}}(f_{l-1}(x)); active selected hops imply r_l(x)>=1. Define

F_p(x,y;g)=product_{l=1}^j gamma / [gamma(r_l(x)+r_l(y))/2+i g].

Then the all-waits integrated path map at fixed final gap g has the explicit entries

T_p,g(X_g)[f_j(x),f_j(y)]
 = chi_p(x)chi_p(y) epsilon_p(x)epsilon_p(y) F_p(x,y;g) X_g[x,y].

No duplicate output pair occurs because f_j is injective. To obtain the physical post density matrix in final energy eigenvectors |b>,|c>, evaluate the contraction <b|T_p,b-c(X_{b-c})|c>. Equivalently sum these terms with |b><c|. These are unnormalized path states. All surviving paths, including zero-mass paths, belong to the graph census; only a reported conditional state divides by its own strictly positive path mass.

The j-event path mass simplifies further:

w_p=sum_x (X_0)[x,x] chi_p(x) product_l 1/r_l(x).

The gamma cancels. The trace only uses diagonal x=y because the path partial permutation is injective and the final energy trace enforces g=0. Thus the path weights are a finite classical exclusion-walk calculation seeded by the occupation probabilities diag(X_0), while currents still require full quantum coherences X_g. In particular X_0 is the battery-induced energy-kernel reduction of the initial state, not necessarily the bare initial matter density. Graph-uniform rational weights cannot be reused. Conditional on a fixed x they are exact products of integer reciprocal rates.
