# Block 35 goal

Determine, at theorem rather than summary level, what the public evidence in
PR #7814 establishes about its central rule claim:

> covariance + Markov locality + triangle-free `Z^d` +
> Hammersley--Clifford + Record consistency force
> `phi(n,m) = a + lambda n dot m`.

The campaign must answer four linked questions:

1. Do the stated public assumptions and the current four axioms exclude a
   strictly positive nonlinear invariant edge kernel?
2. What exact additional physical-consistency property is sufficient to
   reduce the kernel family to the affine form?
3. Does that property select the Born endpoint rather than anti-Born, or is a
   second matching/repeatability condition required?
4. Which headline gravity numerals are independently reproducible arithmetic,
   and which remain unsupported derivation claims because the cited archive is
   absent?

This is an evidence and theorem gate, not review-loop, PR landing, audit, or an
attempt to identify Block 34's amplitude with PR #7814's interaction parameter.
