## 2. Load-bearing step (A) — additivity on effects from (M1)–(M3)

The complement law and partial additivity follow from the parent's exact
hypotheses:

```text
two-outcome POVM {E, 𝟙 − E}:  m(E) + m(𝟙 − E) = 1            (complement law)
three-outcome POVM {E_1, E_2, 𝟙 − E_1 − E_2} (valid when E_1 + E_2 ≤ 𝟙):
                              m(E_1) + m(E_2) + m(𝟙 − E_1 − E_2) = 1.
```

Subtracting, and using the complement law on `E_1 + E_2`
(`m(𝟙 − (E_1+E_2)) = 1 − m(E_1+E_2)`):

```text
m(E_1 + E_2) = m(E_1) + m(E_2)        whenever E_1 + E_2 ≤ 𝟙.   (partial additivity)
```

This is the effect-algebra additivity law. The runner reproves the complement law
and partial additivity exactly on a rational qubit instance (`Part 0`) and
numerically over 2000 admissible effect pairs on `M_2` (`Part 3`, residuals
`~10⁻¹⁶`).

## 3. Load-bearing steps (B),(C) — linearity and the real-linear extension

**(B) Homogeneity.** Iterating partial additivity gives `m(nE) = n m(E)` whenever
`nE ≤ 𝟙` (integer `n`), hence `m((p/q)E) = (p/q) m(E)` for rationals
`p/q ∈ [0,1]` with `(p/q)E` an effect. The bound `0 ≤ m ≤ 1` makes `t ↦ m(tE)`
monotone and bounded on `[0,1]`, so the rational homogeneity extends to all real
`t ∈ [0,1]`: `m(tE) = t m(E)` (the standard Cauchy-on-a-bounded-domain upgrade).
The runner reproves rational homogeneity exactly (`Part 0`, `q = 1/2, 1/3, 3/7`)
and real homogeneity numerically over 1000 seeds (`Part 4`, residuals `~10⁻¹⁶`).

**(C) Real-linear extension to `Herm(M_2)`.** `Herm(M_2)` is the **real** 4-dim
space spanned by `{𝟙, σ_x, σ_y, σ_z}`. Any Hermitian `H` can be written
`H = c_0 𝟙 + c · σ`; choosing a real `α > 0` and `β` so that `αH + β𝟙` lies in
the effect cone, (A)+(B) determine `m(αH + β𝟙) = α F(H) + β m(𝟙)`, which defines
a single real-linear functional `F` on `Herm(M_2)` agreeing with `m` on effects.
`F` is fixed by its four values `F(𝟙), F(σ_x), F(σ_y), F(σ_z)`; equivalently,
`F(σ_a) = 2 m(P_a^+) − 1` since `σ_a = 2P_a^+ − 𝟙` and `F(𝟙) = m(𝟙) = 1`. The
runner evaluates `F` on the basis using only effect-cone values of `m`
(`reconstruct_sigma_from_effect_functional`, used throughout).

## 4. Load-bearing steps (D),(E) — Riesz/trace form and that `σ` is a state

**(D) Riesz / trace form.** On the real Hilbert space `(Herm(M_2), ⟨·,·⟩)` with
`⟨X,Y⟩ = Tr(XY)`, every real-linear functional `F` is represented by a unique
`σ ∈ Herm(M_2)` via `F(H) = Tr(σ H) = ⟨σ, H⟩`. Expanding `σ` in the orthogonal
basis (`Tr(B_a B_b) = 2 δ_{ab}` on `M_2`):

```text
σ = (1/2) Σ_a F(B_a) B_a
  = ½[ F(𝟙) 𝟙 + Σ_{a} (2 m(P_a^+) − 1) σ_a ]
  = ½[ 𝟙 + Σ_{a∈{x,y,z}} (2 m(P_a^+) − 1) σ_a ].
```

The runner reproves the basis orthogonality `Tr(B_a B_b) = d δ_{ab}` on `M_2` and
`M_4` (`Part 7`), and reconstructs `σ` from `m` **blind** to any pre-chosen
operator, verifying `σ_reconstructed = σ_true` exactly on a rational qubit
instance (`Part 0`) and numerically over 400 random qubit measures (`Part 1`,
residuals `~10⁻¹⁶`). Uniqueness is immediate from the orthogonal expansion.

**(E) `σ` is a density matrix.** Normalization (M2) gives
`Tr σ = ⟨σ, 𝟙⟩ = F(𝟙) = m(𝟙) = 1`. Nonnegativity: for any unit `|ψ⟩`, the rank-1
projector `P_ψ = |ψ⟩⟨ψ|` is an effect, and `m(P_ψ) = Tr(σ P_ψ) = ⟨ψ|σ|ψ⟩ ≥ 0`
by (M1)–(M3)-nonnegativity (`m ≥ 0`); since this holds for all `|ψ⟩`, `σ ≥ 0`.
The runner confirms `m(P_ψ) ≥ 0` on random rank-1 projectors and that the
reconstructed `σ` has nonnegative spectrum (`Part 5`), and that the induced
measure satisfies (M1)–(M3) on random POVMs with `n = 2,3,4` outcomes
(`Part 2`).

Combining (A)–(E): `m(E) = Tr(σ · E)` on `E(M_2)` with `σ` a unique density
matrix. This is the Busch / CFMR effect-Gleason representation, reproven on the
qubit from primitives — the load-bearing direction the parent imported by name.
