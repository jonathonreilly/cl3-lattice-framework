# Five-physicist panel return

The panel covered five independent lenses: local/QCA construction,
causal/distributed process, quantum operations, probability/statistical
mechanics, and portfolio/prior art.

## Consensus

1. The M/S compiler is still the highest expected-value TOE seam, but a
   generic compiler would duplicate mature prior art.
2. Use a small state-clocked single front with roles
   `H-R-P-O-C-H`.  Finite phase/controller tags use spatial/Record words;
   continuous Gaussian and program data remain literal `M_2(C)` carriers.
3. The outcome processor must be fixed and program-independent.  The selector
   may control installation, but neither it nor archived payload may be a
   later response parent.
4. `M` is a measure/channel intertwining theorem under a predetermined active
   map.  Global selector/program correlations must remain observable.
5. `S` requires equality of the joint next transcript and next active cut,
   not just the next marginal.  That equality must follow from a
   payload-sensitivity cut in the actual table and be iterated for all `N`.
6. Freshness is a normalized archive-blind stochastic row of the same Markov
   kernel.  Passing an innovation sequence into the runner relocates `S`.
7. A value-blind outcome-to-close signal is allowed.  A payload-sensitive
   `O -> C -> H -> R` relay is the decisive falsifier.

## Mandatory controls

- selector-leak or branch-indexed response processor breaks `M`;
- nonlinear program encoder breaks midpoint equality;
- active effect reading the selector breaks the relative quotient;
- delayed payload relay breaks `S` despite one-step separation;
- frozen hidden cause and a three-use parity deformation break renewal;
- overwrite masquerading as reset is rejected;
- malformed/multiple-front neighborhoods reach defined STOP/identity rows;
- all proper-cubic frames and translated fronts agree;
- exact arbitrary-`N` support and cut induction, not bounded extrapolation;
- exact map to Block 36 `nu(db,dn)`.

## Portfolio verdict

The endpoint/sign selector ranks second.  Gravity is lower until a Record-local
source identity exists; current gravity PRs are operator-side.  Loopy gluing is
lower still without physical edge ownership.  No axiom update is justified.
