# Block 37 goal

Build the smallest explicit microscopic candidate process that retires the two
named Block 36 imports at candidate-law scope.

The process must use one time-homogeneous, translation-covariant and
proper-cubic-covariant radius-one rule on permanent `M_2(C)` Records.  From a
finite relational seed it must implement the physical sequence

```text
head -> Gaussian selector Record -> installed program -> outcome Record
     -> value-blind close -> next head.
```

The selector must form before the program.  The outcome row must read the
installed program, not the archived selector.  The close may transmit the
fact that an outcome exists, but not its value.  The next Gaussian row must be
one row of the same Markov kernel, not an external IID stream.

The primary success theorem has two parts:

1. `M`: randomized and direct-midpoint program procedures have the same
   predetermined algebraic active reduction, so the fixed program-independent
   response processor gives the same active law while permanent selector
   correlations remain globally distinguishable.
2. `S`: configurations with the same active cut and arbitrary allowed old
   selector/outcome payloads have the same joint next-transcript/next-cut law.
   Induction then gives identical active cylinders for every finite horizon.

Success is a theorem inside one selected extensional candidate law.  It is not
a derivation or selection of that law from the four axioms, not a selection of
`lambda`, not a full multi-front or loopy `Z^3` theory, not gravity, and not an
audit/obligation/TOE-score movement.
