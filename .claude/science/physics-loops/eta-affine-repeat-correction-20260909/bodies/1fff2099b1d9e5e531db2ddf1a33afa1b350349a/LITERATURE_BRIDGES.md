# Block 36 literature bridges

No external literature value, experimental comparator, or fitted datum is a
proof input.  The campaign uses elementary probability, finite-dimensional
linear algebra, bounded Jensen reasoning, and normalized sphere measure.

The full-effect qubit representation theorem is known prior art in the repo,
but it is not load-bearing for the selected route.  Introducing it would also
require a physical full-effect repertoire, so Block 36 instead randomizes both
operational slots and uses the smaller cubic-covariant affine theorem.
