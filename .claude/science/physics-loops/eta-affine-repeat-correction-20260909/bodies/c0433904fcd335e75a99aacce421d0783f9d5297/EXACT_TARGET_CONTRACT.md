# Exact target contract

## Target statement

For every input Bloch vector s in the closed unit ball, Haar axis a on S^2,
binary label b in {+1,-1}, response parameter lambda in [-1,1], and
successor-state sharpness kappa in [-1,1], define

    rho_s = (I+s.sigma)/2
    E_b^lambda(a) = (I+b lambda a.sigma)/2
    I_(a,b)^(lambda,kappa)(rho)
      = Tr(E_b^lambda(a) rho) rho_(kappa b a).

The block must prove directly that this is a normalized covariant binary CP
instrument exactly on the declared parameter square, and that forgetting the
recorded latent (a,b) decomposition while retaining n=b a gives

    T_s^lambda(dn) = (1+lambda n.s) mu(dn).

It must then compile a second use of the same axis and same kernel before the
Block-37 close. The second use may read the retained axis and the physical
successor state, but not the first outcome Record. Its exact same-label mass
must be derived as

    Pr(b2=b1 | a,b1,successor) = (1+lambda kappa)/2.

The Block-37 pure-outcome attachment gate must be typed independently of the
probability row: its unit-sphere outcome Record n=b a denotes the pure matter
possibility rho_n, so a record-faithful successor has kappa=1. Only after that
typing may exact operational repeat certainty select lambda=1. The selected
ordinary-output marginal must then equal the actual Block-37 Haar row without
a fit or label-only identification.

Finally, one radius-one, translation/proper-cubic-covariant, finite-rate local
generator must realize the ordered dependencies

    program -> recorded Haar axis -> first binary branch + successor state
            -> second same-axis branch -> physical outcome -> value-blind close
    protocol rail -----------------------------------------------> next cut

on a finite single-front sector, with commuting co-enabled jumps, no host
scheduler, no archive relay, no overwrite, and a preserved cut suitable for
arbitrary finite induction.

## Allowed premises

- Current Lattice, Qubit, Admissibility, and Record axioms, only at their
  literal current scope.
- Exact finite-dimensional M_2(C), CP/Choi, convexity, Haar, and Markov-kernel
  mathematics reproved or checked in packet.
- Block 35's affine/covariant response-class reduction as conditional source
  context.
- Block 36's operational randomizer/reset construction and Block 37's local
  M/S compiler as source-bound conditional parents.
- The explicit operational calibration question: whether the same attached
  local read is exactly repeatable. If it is not derived by the executed
  process, it remains a named conditional and the status must stay
  conditional-support.

## Forbidden weakenings and imports

- No hard-coded lambda=1, Born factor, projector effect, or repeat result.
- No use of the first outcome Record, copied bit, or archive value in the
  second interrogation.
- No different calibration kernel, parameter, axis law, or post-state rule.
- No selection from a measure-zero singleton of the atomless Haar law.
- No identification of six-axis cubature with the atomless outcome measure.
- No imported Lueders/Born theorem as the load-bearing selector.
- No observed frequency, fitted value, empirical comparator, gravity result,
  or new axiom/primitive.
- No claim that Record permanence alone implies future repeat certainty.

## Required edge and hostile cases

Test lambda=-1,0,1, strict interior depolarized values, kappa=-1,0,1, mixed
input s=0, pure aligned/anti-aligned input, both convex-mixture endpoints,
latent-label reversal, mixed post-state, fresh independent axis, first-Record
relay, hard-coded repeat, effect-only/no-instrument typing, different
ordinary/calibration parameters, nonlinear response competitors,
host-scheduled reuse, collision ambiguity, and TOE-promotion wording.

## Completion witness

A candidate-complete block needs all of:

1. Symbolic and exact finite checks of normalization, positivity, CP Choi
   matrices, covariance, Haar pushforward, and repeat mass.
2. An explicit record-faithful attachment/type graph that does not assume the
   response probability.
3. A local generator graph with exhaustive reachable-state, diamond,
   absorption, placement, and mutation checks.
4. A proof-bearing preserved-cut induction and direct checks that the parent
   M/S identities survive the new factorization.
5. Source/prereg fingerprints and a source-bound cache with FAIL=0.
6. An honest claim certificate that distinguishes conditional selector
   support from axiom-derived or audit-retained closure.

## Outcomes that do not count as closure

The already-known static binary-repeatability lemma, a matrix-only Born trace
calculation, label copying, re-reading the old Record, a six-axis test standing
in for Haar, a branch that inserts rho_n without the attachment graph, a finite
path without a local generator, or a result conditional on repeatability that
is described as axiom-derived does not complete this target.
