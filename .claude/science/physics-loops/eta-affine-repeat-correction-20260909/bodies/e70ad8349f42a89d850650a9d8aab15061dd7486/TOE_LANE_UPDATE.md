finite-tree, and append-only finite-history pieces can coexist in one exact
candidate construction without importing trace/Born weights. That is a real
compatibility advance and removes several possible algebraic contradictions.

that global procedure identical to a separately direct midpoint. The local
constant-channel Choi objects agree, while a permanent selector Record keeps a
global discriminator. Likewise, moving old Records one radius-one step away
does not guarantee permanent predictive screening, because a local copy relay
can later re-enter the active causal cone.

Those controls collapse the main autonomy gap to two explicit physical
lemmas: (M) the active response factors through the reduced installed program
despite the globally readable selector Record, and (S) no archive-value path
can reach any later active worldtube. The present candidate supplies both; it
does not derive them from the four axioms.
