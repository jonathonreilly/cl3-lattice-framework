## Claim (negative)

Under **L1** — a diagonal link defined as the ordered product of
nearest-neighbor (NN) link variables along a chosen NN path — the diagonal
**carries no new degree of freedom.** Its holonomy is **fully determined by the
NN connection variables** and the path. The spread over different path choices
is exactly the plaquette field-strength data that the framework's existing
Wilson-loop machinery already contains. **L1 adds zero new content.**

This note **does not change axioms** and asserts no closure. It is
frame-clearing: it removes L1 from consideration so that any nontrivial content
of the diagonal thought experiment must live at L2 (independent connections) or
L3 (weighted nonlocal paths), tested in the sibling phase notes.

## 1. Face-diagonal (1,1,0): two paths, difference = plaquette

Take a uniform background connection with NN link variables `U_x, U_y` in
`SU(2)`. The face-diagonal from a corner to `(1,1,0)` has two NN paths:

```text
path A (+x then +y):   W_A = U_y U_x
path B (+y then +x):   W_B = U_x U_y
```

Both are words in the NN links — no free parameter is introduced. Their ratio
is the standard ordered plaquette (the lattice field strength `F_xy`):

```text
W_B W_A^{-1} = U_x U_y U_x^{-1} U_y^{-1} = P_xy        (the plaquette F_xy)
```

So the two path-holonomies differ by **exactly** the curvature already encoded
in the NN connection. To leading order in the lattice spacing `a`, with
`U_μ = exp(i a A_μ)`,

```text
log P_xy = -a^2 [A_x, A_y] + O(a^3),
```

i.e. the plaquette **is** the commutator field strength `[A_x, A_y]`. When the
background is flat (`P_xy = I`, e.g. an abelian sub-connection), the two paths
**agree**: the diagonal holonomy is path-independent and still carries no DOF.

## 2. Body-diagonal (1,1,1): six paths, all related by face plaquettes

The body-diagonal to `(1,1,1)` has `3! = 6` NN path orderings of the steps
`{x, y, z}`. All six holonomies are words in `{U_x, U_y, U_z}`. Any two differ
by a product of face-plaquette holonomies: swapping two adjacent steps in an
ordering multiplies the holonomy by a (possibly NN-conjugated) plaquette
`P_xy, P_yz` or `P_xz`. For example,

```text
W_{x first} W_{y first}^{-1} = U_z (U_y U_x U_y^{-1} U_x^{-1}) U_z^{-1}
                             = U_z P_yx U_z^{-1}.
```

So the six body-diagonal holonomies live in a single coset modulo the subgroup
generated by face plaquettes. When all face plaquettes are trivial (flat
background) **all six coincide** — again zero new DOF.

## 3. Degree-of-freedom count

A face of NN links carries `4` `SU(2)` variables = `4 · 3 = 12` real
parameters. An L1 diagonal adds a holonomy that is a **fixed word** in those
parameters:

```text
L1 diagonal degrees of freedom added = 0.
```

The only "extra" data — the path-dependence — is the plaquette curvature, which
is not new: it is the framework's existing field strength.

## 4. Conclusion

L1 is empty as a source of new physics. It cannot close GATE-COLOR,
GATE-CHIRALITY, or GATE-R-HALF, because it introduces nothing the NN connection
did not already contain. Therefore:

- any genuine content of the diagonal thought experiment requires **L2** (each
  diagonal carries its *own* connection variable, independent of the NN links)
  or **L3** (distance-weighted, site-dependent, nonlocal connections);
- the governance cost of L2/L3 (primitive-level / import; see the scoping note)
  is only worth paying if L2 or L3 actually closes a gate.

Those questions are the subject of the L2 dimension audit and the two gate
tests. This note's role is solely to certify that **L1 adds zero new content**
and clear it from the board.
