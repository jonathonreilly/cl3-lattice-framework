# Static pair-sector support at the supplied RK point

## Precise conditional result

Use the notation G_v=sum_incident n_e−3, Q_v=epsilon_v G_v, n_e=(1−Z_e)/2 and epsilon_v=(-1)^sum(v). For supplied J>=0 and U>0, consider exactly

 H_RK = J sum_p F_p(I−S_p) + U sum_v Q_v²,

with no hopping term (t=0). Then the global minimum is0. For any two distinct vertices u,v, the nonempty sector Q_u=−1,Q_v=+1,Q_w=0 otherwise has exact minimum2U, independently of graph distance. Reversing u,v gives the opposite assignment. The nonnegativity condition J>=0 is necessary to the argument and was added before computation; U>0 alone does not control the ring term. Nonnegative individually weighted J_p also work.

This is a special frustration-free finite-sector statement. It is not a photon, a mobile fermion, a general detuned coupling result or an axiom-selected Hamiltonian. ## Nonnegative rings and zero states

The already proved whole-carrier unitary W maps S_p to the unsigned product X_p of face-link X operators and leaves electric functions unchanged. F_p selects the two alternating face patterns and commutes with S_p. Thus F_p(I−S_p) maps to F_p(I−X_p). Each such term is zero off its alternating subspace and has matrix [[1,−1],[−1,1]] on each paired configuration subspace. It is positive semidefinite, with eigenvalues0 and2.

Fix a realizable full vector of charges q. Alternating face flips preserve every G_v, hence every Q_v. Make the finite configuration graph whose vertices have that charge vector and whose edges are its allowed alternating face flips. For any nonempty component C, the normalized uniform vector

 |Omega_C> = |C|^(−1/2) sum_(x in C) |n(x)>_f tensor |x>_g

is annihilated by every F_p(I−X_p): each active configuration is paired with another member of the same component, and inactive terms vanish. Here n(x) is the mod-two incidence occupation required by the Gauss dictionary, not the original edge bit. On a fixed charge vector it is fixed, but that is not needed for the pairing argument. In original native coordinates the vector has amplitudes conjugate(d(x))/sqrt(|C|), not necessarily positive uniform amplitudes. Ignoring this phase would be an incorrect claim about the native state.

Therefore the minimum in every nonempty fixed-q sector is exactly U sum q_v². The only remaining obligation for the asserted pair energy is nonemptiness for every ordered distinct vertex pair. No uniqueness, component connectivity beyond the chosen component, or count of ground states is required. Frozen singleton components also have zero ring energy.

## Directed path construction for every pair

An ice configuration exists: for the positive-axis link at r in direction a choose n_a(r)=r_a mod2. Along each axis the two incident bits sum to1, giving degree3; even periodic extents make this globally consistent.

More generally, start from ANY ice configuration. For an unoriented edge {i,j}, define antisymmetric electric values E_ij=epsilon_i(n_ij−1/2)=−E_ji. Draw an arrow i→j when E_ij=+1/2. At an ice vertex, Q_i=sum_j E_ij=0, so there are exactly three outgoing and three incoming arrows. The underlying graph is connected.

A finite connected balanced directed graph is strongly connected. For completeness, collapse its strongly connected components to a directed acyclic graph. A source component has no incoming edge. Summing indegree-minus-outdegree over its vertices gives zero by balance, so it also has no outgoing edge. Underlying connectivity forces it to be the entire graph. Therefore there is only one component. This is stronger than just saying an Euler tour exists and makes the required ordered reachability explicit.

There is consequently a directed path from any u to any v. Remove loops to make it simple. Reverse the arrows of all its edges, equivalently toggle their n bits. Each traversed electric value changes from+1/2 to−1/2, so its change is−1 in the path direction, not−2 or−1/2. At internal vertices one entering and one leaving contribution cancel. At the endpoints the resulting charges are Q_u=−1 and Q_v=+1, with all others zero. Every intermediate prefix has the same pair pattern at u and the current tip, so the configuration also stays within the low-charge domain during this combinatorial construction.

This proves existence of a basis vector in every specified pair sector. It is not a protocol generated by the displayed t=0 Hamiltonian or native T. Native T cannot create the first pair from the zero-charge all-B-minus domain; it conserves hole number. The comparison also changes native number from |V| to |V|−2. The sector-energy statement must not be described as dynamical preparation within a fixed native-number sector.

## Energy and separation

At q=0, the seed and its ring component supply a zero-energy vector. All terms of H_RK are nonnegative, so E0=0. In a pair sector, the U term is identically2U and the ring term is nonnegative; the uniform component construction attains2U. Thus

 E_pair(u,v)−E0=2U.

If one defines the static string coefficient as this charge-sector cost divided by graph distance, then along any sequence of such finite tori and pairs whose distance diverges, with fixed U, the coefficient tends to0. The exact finite cost is separation independent. This does not assert the existence of an infinite-volume charged ground vector, a temporal Wilson-loop potential, deconfined propagating excitations or an infrared gauge phase.

All electric winding sectors are allowed in the existence statement. The directed path may wrap around the torus and can select a final electric-flux sector. No claim is made that every additional prescribed winding sector contains every pair pattern. The original fixed magnetic cycle code is also not imposed. Open boundaries, missing edges, odd extents and changed coordination require separate backgrounds and reachability arguments and are outside the theorem.

The model is at the supplied RK equality of diagonal and ring coefficients and at t=0. Detuning or enabling charged hopping changes the spectral problem; the exact result is not extrapolated to those regimes. The RK graph-Laplacian mechanism is standard mathematical context. The native contribution here is its exact phase-correct common-carrier use and the specified charged-sector support proof. No physical parameter or formation rule is selected.
