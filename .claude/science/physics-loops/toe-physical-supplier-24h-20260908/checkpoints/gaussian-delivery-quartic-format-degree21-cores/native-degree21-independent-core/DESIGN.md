This new source imports no producer modules. It generalizes exact ordered exponential words to arbitrary finite variable count, represents endpoints as four-tuples (left power, source, right power, source), and reconstructs projected logarithm powers and scalar Euler coefficients. It collects pure-free cancellation and independently tests complete cyclic one-defect coefficient collapse before omitting higher linear traces. One-defect operators are retained for products.

`reconstruct(mask,factors,J,D,P,emit)` accepts exact rational complex pairs and explicit finite source-table callbacks. It can express the degree21 inner mask(2,2,4) and nominal mask(2,2,1,1), with three/four source ranks encoded in explicit labels. It does not import or parse any physical source. Callback events carry A entries, first traces, log-power entries and scalar coefficients; future serialization should encode alpha as an integer list and entries as sorted `(left_power,left_source,right_power,right_source,re,im)` rows with canonical rational components.
