# A quartic inverse-square envelope using ten moments

Source-only conditional proof. No native scalar, moment, trial coefficient or residual value was evaluated. This is a new estimator for the already fixed quadratic first polynomial, not a replay or relabeling of an earlier protocol.

Let delta,tau1,tau2 be strictly positive. Define
 P(x)=(x-delta)(x-tau1)^2(x-tau2)^2,
 b=1/(delta*tau1^2*tau2^2),
 a=b*(1/delta+2/tau1+2/tau2),
 Q(x)=[1+P(x)(a*x+b)]/x^2.
At zero, P(0)=-delta*tau1^2*tau2^2 and P'(0)/P(0)=-1/delta-2/tau1-2/tau2. Thus the numerator's constant and linear coefficients vanish exactly: Q is a polynomial of degree4. For x>=delta,
 Q(x)-x^-2=P(x)(a*x+b)/x^2>=0.
This proof allows coincident tau values and tau=delta; it requires no divided-difference denominator or interpolation pivot. The polynomial is positive on the full half-line although individual coefficients can be negative. No compact spectral-support assumption is used. This is the two-double-contact member of the general construction with any finite product of squared positive contact factors.

If D>=delta is self-adjoint and r lies in the required power domain, spectral calculus gives ||D^-1 r||^2 <= sum_(j=0..4) Q_j rho_j, rho_j=<r,D^j r>. The required moments exist for the supplied local polynomial Gaussian vectors by the separately reviewed GNS/commutator domain argument. For signed Q_j, an upper bound uses the upper rho_j endpoint if Q_j>=0 and the lower endpoint otherwise. It is wrong to multiply every coefficient by an upper moment endpoint. The exact polynomial coefficients can be generated by finite rational convolutions and dropping the two proven zero coefficients.

For an already fixed p(x)=p0+p1*x+p2*x^2, r=(1-Dp(D))Omega has coefficient vector(1,-p0,-p1,-p2), up to an irrelevant overall sign. Then
 rho_j=sum_(a,b=0..3) r_a r_b m_(a+b+j), j=0..4.
This uses m0 through m10, with old m0..6 reused and only the new high-moment supplier providing m7..10. The original p, q, signed nominal and inner source moments s0..2 are unchanged. No mixed nominal or new Wick contraction is required for this new error estimate.

A finite prospective family can use the15 unordered pairs with repetition from positive contacts{1,2,4,8,16}. These are proposals fixed before evaluation, not continuous optimizers. All60 class/choice envelopes (two P/O classes in each of two original modes) reuse the same four sets of five residual moments. Each rho needs16 interval products; the complete first-residual acquisition therefore needs at most320 signed moment products, followed by60 five-term envelope evaluations. This is an arithmetic count, not a wall-time forecast. Compare each nonnegative certified upper envelope with that SAME trial's original gap estimate and take their minimum before an outward square root. A negative upper norm bound is a discrepancy requiring refusal, not clipping. Any earlier bound from a different polynomial is ineligible.

For constant q, b_A=J_A p_A(D_A)Omega and s_j=<b_A,D_A^j b_A> are already accepted. The inner residual norm squared is Rb_A^2=s0_A-2q_A*s1_A+q_A^2*s2_A. With ||J_A||=sqrt8 in h=1 units, a safe channelwise second error is
 v_A <= (sqrt8/delta) u_A + Rb_A/delta,
 where u_A bounds the new first inverse error. Aggregate E^2=12u_P^2+3u_O^2 and F^2=12v_P^2+3v_O^2. The coupling term cannot be omitted. Retain raw signed inner quadratic forms before roots and do not recompute their old native moments.

The already reviewed posterior Ward bound can now use this E,F with the same original trial norms a0,b0 and nominal W0:
 |W-W0| <= 6*[ E*(a0+chi)+min(E*b0+chi*F,E*psi+a0*F) ],
 chi=min(X,a0+E), psi=min(V,b0+F).
X,V are the same separately supplied exact-state bounds. This update changes only the error certificate. It may be compared/intersected with a prior accepted interval only when all state, trial, nominal and unit identities match. It promises no positive endpoint. The fixed high-moment1e-6 pilot target does not automatically certify adequate accuracy for these signed high-degree contractions; actual enclosures and original moment uncertainty remain in every rho.
