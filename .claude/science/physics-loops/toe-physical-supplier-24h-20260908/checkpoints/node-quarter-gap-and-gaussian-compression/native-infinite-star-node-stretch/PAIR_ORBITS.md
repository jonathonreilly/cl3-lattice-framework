# Five centered cubic pair classes

The90 ordered disjoint two-edge pairs can be grouped into five orbits of the octahedral stabilizer of the center. With neighbors named +x,-x,+y,-y,+z,-z, representatives and sizes are:

1. A={+x,-x}, C={+y,-y}:6.
2. A={+x,-x}, C={+y,+z}:12.
3. A={+x,+y}, C={+z,-z}:12.
4. A={+x,+y}, C={-x,-y}:12.
5. A={+x,+y}, C={-x,+z}:48.

Signed coordinate permutations are restored to the pi gauge by vertex gauges generated by (-1)^r_a for reflections and (-1)^(r_a r_b) for adjacent-coordinate transpositions (a,b). General coordinate permutations use compositions of these generators, with each gauge evaluated in the successively permuted coordinates; the same monomial must not be assigned to an arbitrary transposition. For example, x↔z uses (-1)^(xy+xz+yz). These are +1 at the origin and on2Z^3, so they fix gamma_v and the generalized node vector q, and map the actual defect family and reference state covariantly. The node scalar of each word is therefore constant on these orbits. Formula(B)'s90 summands may be replaced by five representatives with exactly the displayed multiplicities and overall1/8. No A,C-exchange equality or positivity is needed; all five signed integrals are retained. This reduces redundant point evaluations without changing the model or selecting favorable terms.
