# Incremental reptation core: implementation proof and scope

The production L2/L4 source fcd0956c is copied unchanged as slow_original.py. Only the scratch reference's size guard is relaxed for L8 comparison; its full recount and transition logic are unchanged.

For a proposed toggle of face p, the only flippability predicates that can change belong to faces sharing at least one edge with p. Precompute each edge's incident-face list, then union these four lists. Counting legal patterns before and after toggling those entries gives the exact integer difference in Nf. Every other face sees identical bits. This argument holds for any state, including nonlegal hypothetical toggles; physical proposals still test legal(p) first. On the periodic cubic L>=4 fixtures this union contains13 faces. A self label changes no state, Nf or Fourier value and returns immediately.

The adjacent path state needed in the acceptance ratio is obtained conceptually by the deleted end label. The incremental routine computes its Nf directly without allocating that complete state. Accepted endpoint/midpoint updates use the same local difference before changing bits. The label ring, proposal interval, acceptance ratio and reject-only direction reversal are unchanged. Thus, given identical uniforms, the new and slow algorithms give identical events by induction from equal initial paths. Fourier changes are the linear sum over four flipped edges, retaining all twelve complex channels for harmonics1,2. Finite arithmetic introduces the reported tiny roundoff only; no probability approximation is added by the Nf optimization.
