# Verified CT L4 reference adapter

This is a deterministic implementation candidate, not a stochastic calibration, cost profile or local-index port. It targets the supplied finite CT free-endpoint law at total time T, with midpoint projection T/2. Existing studies and canonical files are untouched.

bridge.py and geometry_reference.py are byte-identical to the reviewed22ab dependencies. All Conditional and Tape methods and transfer/bridge helper functions have identical ASTs to that conditional source. The only conditional change removes the mutable reference Trajectory class and replaces the final draw witness-construction tail with Trajectory.from_conditional. All amplitudes, messages, inverse-CDF operations, variate consumption, selected events and quotient checks are unchanged. Forty-eight actual fixed-tape block pairs on L2/L4, T=.5/2 and nontrivial witnessed paths agree exactly with the full reference in states, events, witness and receipts.

The new object is immutable, as is its geometry. Public construction/load validates the complete witness and physical trajectory. Each old physical state has proven ice and component membership. A conditional result must have either the same initial state or its legal selected-face flip; only that legal flip can append to the persistent immutable witness. Every new event is checked for valid label, strict positive ordering and actual flippability, and all nonselected physical events must remain identical. Thus local legal-flip induction preserves ice and reachability; it does not assume unknown component connectivity. Cached final state follows from the same replay. The object check() returns this verified cached endpoint; full_check() explicitly replays witness, ice and events at external save/validation boundaries. Adapter rejects mutable reference objects. This is an internal trusted-code invariant, not a security claim against arbitrary object.__setattr__ or monkey-patching the implementation.

The persistent witness appends in O(1) without L2 BFS or repeated replay. Its full materialization/save still costs O(witness length). Selected-face blocks still scan all physical events and use global NF; the reviewed persistent local index is NOT installed. Global initialization, measurement and checkpoint costs remain present. There is no speed or mixing inference.

Readouts use exact integer fourth-root real/imaginary sums for six transverse channels at each harmonic. L4 exposes h1=pi/2 and h2=pi with fifteen same-snapshot moments. L2 exposes only its original twelve readouts and one physical harmonic; no fictitious second harmonic is reported. The L4 values agree with independent direct complex sums and Fraction-based literal path observables. The general denominators are4*volume for X,4*volume² for corner,3*volume² for anisotropy and3*volume*T for four-link event activity. Endpoint h=(V-1)NF uses the declared rational V. The balance V*timeNF-eventCount/T-Eavg is a same-time diagnostic whose stationary expectation vanishes, as derived in the preceding design; it need not vanish on individual paths.

Tape-driven propagated initialization performs exactly the declared finite RK preparation and then rate-M RK uniformization, retaining legal flips and discarding self moves. It supplies a valid path, not a detuned stationary state. Clock zeros, exact endpoint collisions, nonincreasing time, tape exhaustion and budget exhaustion fail the whole call without retries. Ordinary floating exponential waiting times have no claimed exact machine-law guarantee. The fixed prospective profile uses V=.95 only; accepting V in[0,1] in this deterministic adapter does not authorize additional models or runs.

Controls run under-OO with explicit exceptions. They include literal L4 readouts, legacy L2 equality, original-root immutability, checkpoint full revalidation, corrupted witnesses/times, deleted retained events, integer initialization counts and clock failures. Actual phase and stale-endpoint source mutants fail the relevant mathematical checks; predecessor control/source revisions are preserved. No original failed study is superseded by these controls.
