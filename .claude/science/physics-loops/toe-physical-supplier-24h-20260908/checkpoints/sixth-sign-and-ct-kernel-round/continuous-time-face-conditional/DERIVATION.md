## Distant-event identity

Delta_p Nf depends only on the edges belonging to faces touching p. If q's edge set is disjoint from that full dependency set, then q cannot alter p legality or Delta_p Nf, and q legality is the same on the two p alternatives. The flips commute. Therefore retained q gives a bijection between the two orbits (or the singleton orbits). Transport the following orbit coordinates through this bijection C. Its local generator is the preceding generator plus a scalar identity, since the diagonal difference and offdiagonal rate agree. Consequently

  exp(t0 B0) C exp(t1 B1) is proportional to exp((t0+t1)B0) C.

The code compares normalized matrices, so this scalar disappears. The strict dependency test is sufficient, not necessary. Partial compatibility or a nearby event is not merged merely because one numerical difference happens to coincide. merged_pair returns only an equivalent transfer matrix for verification; it does not delete the retained physical event or change output reconstruction. Lazy event indexing and efficient global reconstruction are unimplemented.
