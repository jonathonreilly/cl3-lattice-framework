# Deterministic implementation checkpoint

The packed-state face-fiber sampler is implemented and tested, with no stochastic micro or production. Its target is the supplied positive finite product-G path law with free endpoints, V<1, and the seed-reachable legal plaquette component. The mathematical parent is ../interior-projector-sampler-panel/DERIVATION.md (2311f3d2), with its preserved ALIAS_CLARIFICATION.md. Root independently derived the same block before receiving the author's recommendation.

core.py uses Python integer packed configurations and a complete Nf cache at every time slice. Constructor validation checks every binary state, ice constraint, positive path bond, and a legal seed-to-first-state witness. Thus it does not identify all zero-flux states with the seed component. Each orbit is canonically sorted and singleton-deduplicated. Candidate Nf values use affected-face differences; all transition entries use actual endpoint differences and geometric multiplicities, including L2 duplicates. Fraction V makes every transfer entry exact. Backward messages and inverse-CDF draws are floating arithmetic driven by explicitly supplied variates; this is not an exact random-number or interval-arithmetic claim. Zero/nonfinite normalizers and invalid variates reject. No RNG or production launcher exists.

The first run passed 6352 explicit predicates: 312 complete exact restricted conditional laws from 13 fixed L2 paths, exact mass comparisons, every positive-output fiber partition, flux and cache checks, and five supplied-variate vectors per fiber against direct Fraction enumeration. A constant-path separated flip interval has positive mass. Actual wrong-transition and pinned-endpoint source mutants disagree with the exact law. Original scripts, mutant bytes and raw results are retained.

A separately preregistered supplement passed 62516 predicates. It independently traversed the literal 864-state L2 seed component and checked all allowed move caches and multiplicities. A deterministic 64-move L4 walk checked packed changes, flux and every selected-face transfer entry: 16209 positive and 7758 zero entries. Other-face bonds in these L4 fixtures retain their original nonself difference when positive; the column choices are constrained by those bonds. Existing self/p-face labels can change, so retaining the entire old label sequence would be invalid. No universal claim about arbitrary graph bond masks is inferred from this fixture.

The supplement also verifies root's correction: uniformly duplicating singleton aliases is harmless after pushforward. It is not reported as a failed mathematical mutant. The original panel wording and the correction are both preserved.

Run costs were 1.1602 s / 20.9063 MiB and 1.6355 s / 19.1406 MiB, respectively, under -OO with explicit exception predicates and 180-second alarms. These are deterministic verification costs, not algorithm throughput profiles. There is no measured mixing gain.

The path-state payload uses one packed integer per slice rather than one byte per link. Geometry initialization and full validation deliberately remain straightforward: initial Nf recount costs O(n M), and an explicit post-draw check repeats that cost. A face conditional itself has O(n) transfer/message work at fixed bounded local degree using affected-face caches and mask lookup. M face blocks, not one block, constitute a nominal spatial sweep. Message/object overhead, packing, measurement, checkpoint and useful independent-sample cost have not been profiled. The prototype is therefore not yet a reviewed high-throughput backend.

The next gate is independent full source/conditional review. Any later mixing experiment must retain physical observable autocorrelation, independent-chain covariance, and initialization contrasts. Interior overwrites destroy the interpretation of original reptation tags; merely removing those tags is not evidence of equilibration. All completed failed L8 evidence and the unlaunched V0 pilot remain untouched.
