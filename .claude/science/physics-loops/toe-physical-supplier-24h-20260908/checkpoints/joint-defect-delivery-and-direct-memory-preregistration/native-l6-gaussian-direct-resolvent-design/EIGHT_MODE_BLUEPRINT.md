# Exact active/spectator reduction for both declared pair classes

This supplements, not replaces, d7530874. Read actual pinned coefficient rows: center a is supported precisely at0,6,12,18, all nonzero. Baseline frequency blocks have sizes6,6,6,3. The pair classes use neighbors(36,6) and(36,180), each with k=-2.

Within each block decompose b into its coordinate along a and perpendicular vector w. An SO(d−1) rotation fixing the center coordinate can align w to the next coordinate. It needs at most d−2 plane eliminations:4+4+4+1=13 for the four blocks. If w=0 choose identity; no division by zero or forced rotation is needed. Exact rational sums of native squared coefficients establish that w is nonzero in every block for both classes. Squares for P are160/81,64/27,8/9,8/81; for O are64/81,64/27,16/9,32/81. These are sums after k=-2 is included. Controls used the exact value/sqrt(norm) rows and verified common per-mode denominators before adding numerators; no floating native action.

After alignment the active coordinates can be fixed as J=(0,1,6,7,12,13,18,19). The complementary13 coordinates are spectators. Both a and b have support in J, so M=diag(omega)−2ab^T has an8x8 active block and diagonal spectator block, with no coupling between them. Rotating A and B with the same real orthogonal block transformation is number conserving and fixes the vacuum (choose the implementer's vacuum phase to be1). The AA and BB Spin angles have opposite signs for the same coordinate rotation; treating their angles as identical would rotate the two families oppositely. Alternatively implement the induced two-mode occupation block directly.

An oriented SVD of only the8x8 active block requires at most28 planes for each of U,V,56 Spin planes total. Use SO(8) factors and signed singular values; do not discard determinant signs. Active transformed energies are deltaA+sum_{j=1}^8 sigma_j n_j with deltaA=(sum active omega−sum signed sigma)/2. Spectator occupation contributes exactly Es=sum_{j outside J} omega_j n_j. Every denominator is deltaA+Es+sum sigma_j n_j. The full constant formula reduces to this because unchanged spectator vacuum offsets cancel.

A first-source vacuum lies in spectator vacuum, so its exact resolvent stays in the128-dimensional even active Fock sector. One can diagonalize/invert there, embed its active amplitudes with all spectator bits zero, then undo the alignment. This is an exact finite invariant-subspace argument; it does not require the candidate SVD to be numerically trusted. The active mode order is inherited from increasing original indices. Embedding and rotations must use that order's CAR signs; an arbitrary bit permutation without its exterior sign is invalid.

A second source need not have spectator vacuum occupation. It decomposes into8192 spectator occupation blocks. For each block the allowed active parity is total_parity XOR spectator_parity, giving128 active states per block and exactly2^20 total. Omitting Es or projecting to the first-source128 states would be wrong. The active Spin rotations preserve spectator occupations; when implemented in original noncontiguous mode indices their JW signs automatically include intermediate spectator occupations. A packed active/spectator representation instead requires a declared fermionic permutation with its signs.

Full inverse cost bound: into/out of alignment uses26 number-conserving two-mode block passes; active singular rotations use112 Spin plane passes; one diagonal division pass. Thus138 block/plane passes plus diagonal, or164 Spin plane passes plus diagonal if each number-conserving rotation is implemented as two Spin planes. These are worst fixed operation counts per inverse, not timings. For a first vacuum source, active work can occur in128 entries and only the final inverse-alignment13 block passes need touch the embedded large vector. No unproved low-rank shortcut is used for second sources.
