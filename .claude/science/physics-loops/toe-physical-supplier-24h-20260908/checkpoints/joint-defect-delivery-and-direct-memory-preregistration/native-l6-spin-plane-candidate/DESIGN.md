# Real Spin-plane candidate: no physical execution

Input proof: native-l6-gaussian-direct-resolvent-design/DERIVATION.md (frozen hash in INPUTS). This generic plane implementation does not rely on the pending eight-active-mode refinement. It is a candidate building block, not a Gaussian resolvent solver or certified rotation. No SVD, physical2^20 array, benchmark or solve has run.

API apply(x,modes,sector,p,q,theta,kind,inverse,chunk) mutates a writable contiguous real binary64 vector of length2^(modes-1). Modes2..32, p<q, kindAA/BB; chunk at most4096 pairs. Top occupation is reconstructed from lower-bit parity xor sector. Inverse negates sin(theta/2). Coefficients are ordinary libm candidates; no exact-trigonometric or norm-preservation certificate is claimed.

Let i have stored bit p zero, and j toggle p and q (omit top toggle from stored index). These unordered pairs partition the parity sector exactly, including q=top. Set g_i to the input-column sign of G= A_p A_q or B_p B_q. Right generator q acts first. For BB multiply the two input occupations' factors(2n_q-1)(2n_p-1), since p differs from q. CAR gives g_j=-g_i and G²=-I. Thus output_i=c old_i-s g_i old_j and output_j=c old_j+s g_i old_i. Both old values are saved before either write. This realizes exp(theta G/2); inverse uses -theta. The AA and BB conjugation plane signs therefore match the supplied proof rather than sharing an assumed one-particle sign.

The kernel checks finite inputs/results chunkwise. Failure can leave earlier pairs modified: any future caller must reject the entire candidate and retain failure evidence, not reuse partial state as success. Zero angle checks all inputs but makes no writes, preserving signed-zero bits. There is no retry, clipping, normalization or hidden projection.

Memory: one resident caller vector (8MiB for21 modes) plus chunk-sized index/sign/pair arrays. No full parity or permutation table, second full vector or dense Fock matrix is formed. Live named arrays are k,i,j,bits,g,a,b,sg,u,v plus temporary integer-parity and multiplication arrays. Each nonzero plane uses five real multiplies and two additions/subtractions per pair (including sg), bounded index/parity work, four amplitude reads/writes; 2^(modes-2) pairs.
