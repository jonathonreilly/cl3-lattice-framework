# Independent dyadic norm replay

The source scanner obtains significands/exponents directly from uint64 fields. This independent implementation decodes explicit little-endian binary64 pairs via struct('<dd'), rejects nonfinite components, and calls float.as_integer_ratio. For a finite binary64 x=a/2^k in reduced form,0<=k<=1074, so x²=a²*2^(2148-2k)/2^2148. The integer shift is nonnegative, including the largest finite input. Signed zeros both contribute zero. No floating multiplication is used in the sum; as_integer_ratio is the explicit Python-runtime semantic dependency.

Each compressed index gives the lower m-1 occupations. The code independently XOR-reduces those bits starting with total parity to recover the top bit, then accumulates the real and imaginary exact squares into the full particle-number bucket. This differs from the author's bitfield square and bit_count-based expression, while sharing the underlying binary64 mathematics. The file must have exactly16*2^(m-1) bytes; count checks also reject changes/truncation during streaming. SHA256 is computed on the bytes actually scanned. Little-endian decoding is independent of host byte order.

Tiny controls compare squares to Fraction(x)^2 and buckets to an independently enumerated full parity basis, including subnormal/largest finite/signed-zero values. Wrong length,NaN,Inf and invalid domains reject. Maximum test fixture16 entries. No full fixture is generated and no physical/full scan executed.
