# Preflight witnesses

## Positive witness

For `lambda=1`, `W_(a,lambda)` is the sharp controlled-copy writer up to
fragment gauge.  The branch effect is `P_b(a)`, the matching system pointer is
preserved, and a second fresh use repeats exactly.

## Hostile interior witness

For `lambda=0`, the system pointer is untouched while the orthogonal Record
label is a fair independent bit.  The label can be copied permanently, but
it is not a faithful measurement of the system pointer.

For `lambda=1/2`, the same writer is informative but imperfect.  It is the
load-bearing nontrivial interior control.

## Rank witness

The fixed-pure-output map
`J_b(rho)=Tr(E_b^lambda rho)P_b` has Choi rank two for `|lambda|<1` and rank
one at the endpoints.  Thus an interior pure successor requires hidden
environment/Kraus multiplicity.

## Local-process witness

Block 38 already carries a full `M_2(C)` state in `M`, and its second read has
parents only `M,Q6`.  The side rail and archives mean finite locality alone
does not certify a minimal environment.
