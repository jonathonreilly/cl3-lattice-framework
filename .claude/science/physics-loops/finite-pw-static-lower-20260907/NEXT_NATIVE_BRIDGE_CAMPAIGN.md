## One first target: conditional-state sufficiency for a native bridge Record

**Concrete target.** Specify a framework-authorized map C_e from a candidate physical preparation to the actual nearest-neighbor conditions entering Admissibility, and a preparation domain D, then prove on the smallest nontrivial native block that the native formation instrument's complete output law factors through C_e:

  p_e(z | rho, formation at e) = mu_e(z | C_e(rho)), for every rho in D.

The map C_e must be identified from retained/native condition structure BEFORE choosing the target distribution. D cannot be selected after looking at the answer. The readout is the literal permanent physical edge-Z Record, not a numerical function of an unrecorded matter mode, a battery-energy readout, a controller table or a SU3 label.

This is a prerequisite observable/source bridge: it asks whether the probability assigned by a supplied native CAR/Lüders instrument is really the primitive Record formation law on a declared physical condition domain. A positive result could retire that ONE instrument-to-Admissibility compatibility import. It would not yet retire the larger Wilson-action or physical-SU3-observable identification. That remaining distance must be explicit in the report.

**Why this target before an action fit.** A reconstructed effective action is meaningless as a native derivation if changing an unregistered incoming preparation changes the “physical” Record odds at the same registered condition. Conversely, proving a condition-sufficient operational kernel supplies something that can later be tested for composition, locality and an action representation. No Wilson weight, beta value, maximum-entropy principle, detailed balance or additive readout is assumed to obtain it.

## Minimal actual witness and an immediate falsifier

Use a four-vertex CAR path with three physical edge qubits e0,e1,e2 in consecutive lattice sites. It has no cycle stabilizers; its even-parity code is the full eight-dimensional physical space. In the standard positive tree convention,

 B0=Z0, B1=Z0Z1, B2=Z1Z2, B3=Z2,
 n_j=(I-B_j)/2.

Record the middle bridge e1 with the actual native projector Q_z=(I+zZ1)/2. Fix every exterior site, all old Records, apparatus readiness and event location identically. Keep all three edges initially live and use no incoming dwell. Test the two native product codewords

 |100>_(e0,e1,e2)  <-> occupations(1,1,0,0),
 |110>_(e0,e1,e2)  <-> occupations(1,0,1,0).

Both have N=2 and the same two neighboring physical qubits: e0=1,e2=0. The middle native Record is deterministically + in the first and - in the second. This is a proposed hand-derived acceptance control to independently verify in the next campaign, not a newly audited claim here. It needs only literal8-by8 Pauli matrices and both complete sign branches; no SU3 encoding or generic quantum circuit is involved.

This pair immediately refutes an UNRESTRICTED identification that (i) admits both preparations, (ii) defines C_e using only their identical neighbor data/old Records, and (iii) equates their native sharp measurement probabilities with a single neighbor-conditioned formation distribution. It does NOT refute Admissibility. Possible resolutions are that the preparations do not both belong to the actual admissible domain, that the registered physical conditions include additional legitimately derived data, or that this native measurement is not the primitive formation process. Those possibilities are precisely the bridge to settle.

In particular do not assume that identical old Records imply identical complete nearest-neighbor conditions. The memo does not specify all such condition variables. The experiment must explicitly declare and justify C_e. Nor should one claim that measurement of an arbitrarily prepared incoming qubit is automatically the formation of a fresh primitive Record. Conflating these is the likely failure mode being tested.

## Allowed imports, controls and completion criteria

Allowed for the finite test: the actual tree BKSF dictionary and its legal-code theorem; the explicitly conditional native physical edge Record branches; finite matrix quantum mechanics for checking that instrument; a fixed supplied apparatus/readiness and a declared event at e1. These are marked imports, not consequences of M2(C) alone. Compatibility can retire only the declared instrument/condition identification. Born/Lüders probability values remain independent imports unless their own retained derivation is provided; consistency with a native condition map alone does not derive them. If a battery is introduced later, preserve its preparation, cap, refusal and readout contract; it is unnecessary for the first deterministic-sign control.

Disallowed shortcuts: a freely supplied SU3 or Z4 encoder as “native,” a controller that evaluates the desired answer, selecting only successful signs, assigning probability values because a Born formula was programmed, deriving an action by defining minus-log of an already chosen Wilson distribution, or renaming the target's local incoming quantum state as a nearest-neighbor variable without a physical map.

The first bounded session should produce:

1. An exact source-side definition of C_e and D with every dependency classified. If none exists beyond conditional choices, record that fact before any parameter sweep.
2. The literal native matrices for the two preparations and both branches, checking code legality, N, neighbor restrictions, old-Record preservation and complete probabilities. Then test any proposed domain restriction or condition map against this fixed pair and additional coherent states; do not retune it to exclude inconvenient data without a source reason.
3. If a genuine condition-derived preparation channel E_C is proposed, derive it from the named admissibility structure and test whether all allowed realizations of E_C give the same complete Record law. Merely choosing E_C to manufacture mu_C is a failed derivation. Do not demand a coherence claim beyond the declared classical/quantum domain.

**Success:** a retained-grounded condition/preparation theorem establishes the declared native instrument/condition identification on all allowed preparations. If Born/Lüders values are still supplied, state that the compatibility import alone has been retired; claiming the tested likelihoods themselves derived additionally requires their own retained derivation, without inserting those values. State exactly which probability/observable-identification import has disappeared and which action/group/coupling imports remain. A programmable implementation alone is not success.

**Useful negative outcome:** give the explicit pair or compatible alternative preparations, the exact differing probabilities, and name the absent preparation/condition or formation-instrument identification. This excludes one proposed bridge/domain, not every possible native dynamics. Do not spend a full campaign republishing the already obvious unrestricted-preparation failure; use it as an early discriminator for serious proposed bridges.

**Stop rule:** if the only offered “repair” is another chosen distribution, chosen controller or post hoc domain, there is no source/action retirement. Archive the precise failed proposal and switch lanes. Do not optimize batteries or enlarge the SU3 cutoff to disguise the missing premise.
