# Pre-execution panel amendment

This amendment was recorded after preregistration commit `6b05640a95` and
before the primary runner was written. It narrows assumptions and strengthens
live constructive escapes; it does not weaken any kill gate.

## Measure generality

The total-hazard/determinant identity needs only a normalized mark measure with
zero first moment. Recovering the full Bloch vector from Record marks needs the
isotropic second moment

```text
int n dmu(n)=0,
int n n^T dmu(n)=I/3.
```

Normalized Haar measure is one realization. The uniform six signed cubic axes
are a finite realization. Registered binary PVMs along three recorded axes are
an operational tomography realization. Haar support is therefore not to be
called forced by the cross-calibration theorem.

## Grading-safe carrier escape

The two-qubit fixed-even sector carries the full logical Record qubit but has
no orthogonal blank inside that same sector. Three physical qubits are the
first global-parity block with enough even dimension for both:

```text
|B>   = |000>,
|0_L> = |011>,
|1_L> = |101>.
```

All three vectors have parity `+1`. Every logical `P_L(n)` and every jump
`|n_L><B|` is parity-even. This is an exact finite carrier escape without
enlarging any one-site `M_2(C)` algebra.

It does not yet make a literal current-axiom Record: composite Record identity,
joint writing, decoder, covariant block allocation, overlap arbitration, and
cross-site product remain supplied.

## Physical interpretation firewall

Every strictly positive `W` can be written `exp(-A)` for `A=-log W`.
Consequently “action-generated by exponentiation” is only predictive when the
action is fixed independently before Record data. A common scalar shift is
degenerate with the overall rate unit; an `eta`-dependent scalar shift is
clock-free observable through races.

The candidate primitive wording, if the owner later requests it, should be a
downstream formation law rather than a reinterpretation of the four ontology
axioms. No axiom edit is made in this campaign.
