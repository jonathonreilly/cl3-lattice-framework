# Goal

Test whether one exact two-slice reflection-positive Berezin action on the
four-site square can generate, without a separately supplied Fock operator,
the complete finite chain

```text
cross-slice action kernel K
  -> OS functional and reflected inner product
  -> normalized reconstructed CAR fields
  -> coherent-boundary coefficient matrix Gamma(K)
  -> positive two-step transfer and its local generator
  -> U(1) density/current and a product-sensitive occupation event
  -> one common pointer Record instrument.
```

The direct target is the named action-to-Fock operator-identification gap in
`FREE_STAGGERED_D_DIMENSIONAL_TWO_STEP_MANY_BODY_TRANSFER_IDENTITY_NOTE_2026-07-20.md`,
but only on this declared finite quadratic action.  The block does not claim
to derive the action from the four minimal axioms, select the general
staggered forward channel, derive Record formation, or infer relative Born
weights from one deterministic support test.

A pass is valuable only if the transfer matrix is extracted from the
Grassmann cross-kernel coefficients with normalization and composition
checked.  Constructing `Gamma(K)` independently and noticing that it fits is
not a pass.
