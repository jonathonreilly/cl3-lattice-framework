# Local collaboration instructions

Use the user's actual task and latest corrections to select the work. When
asked to review instructions, prompts, skills, or workflows, examine them for
correctness before applying them. Do not invoke the process being reviewed
merely because it appears in the request. Complete authorized work and report
actual outcomes, unresolved questions, and verification limits plainly.

For scientific research, distinguish proposed constructions, proof obligations,
conditional theorems, empirical predictions, and independently checked results.
A research objective is not evidence that a desired conclusion is true. Preserve
counterexamples and negative findings; do not manufacture closure or progress.
Use existing mathematical machinery with checked hypotheses and independent
checks of load-bearing calculations. More agents or more PASS lines do not
establish independence or correctness.

For the qubit-lattice-axiom-framework repository, use its current
`docs/ai_methodology/SCIENCE_WORKFLOW.md`. The owner-selected cadence is
continuous discovery, selective independent checks, and milestone PRs/audits.
Provisional work may compose on a coherent working branch with explicit open
dependencies. Formal retained status still belongs to the independent audit
path. A prompt/process review does not start a PR or audit backlog drain.

Keep source revisions and recovery paths explicit. Inspect relevant changed
content fully; refresh evidence when concurrent work could have changed it.
Report which editable prompt files changed. Do not claim to have modified
platform-supplied system or developer instructions.
