## Fixed-order endpoint proof and the censored frontier defect

Fix a labeled finite set of sites, a known deterministic order, blank start, nonempty table menus and the source's uniform lift on each menu. Each step appends a value permanently at its site. Let P_T be the resulting probability distribution on complete endpoint configurations, and let R(T) be the set of table digits queried at some positive-probability prefix under T.

If T' agrees with T on R(T), induction over the order gives identical positive-probability prefixes and identical conditional menus at every step: the first possible divergence would be a query in R(T), where the tables agree. Hence P_T=P_T'. The other digits can be varied independently.

Conversely P_T=P_T' determines equal distributions of every prefix by marginalizing the complete endpoint over the as-yet-unassigned sites. At a positive-probability prefix, divide the joint probability of prefix plus next value by its prefix probability. The resulting conditional distribution gives the exact nonempty menu. The shell profile and its flip orientation are fixed by the prefix, so this determines the queried digit uniquely. Therefore equal endpoint laws force agreement on every digit of R(T). Thus, over the full declared 3^24 support-table family,

    |{T' : P_T'=P_T}| = 3^(24−|R(T)|).

This is a finite exact theorem under the supplied order/lift, not a dynamics theorem from the axioms. It is sharper than the source's one-digit observation. A censored frontier observes R_seen ⊆ R(T), so 3^(24−|R_seen|) is an UPPER bound on that fibre, not the claimed lower bound. When no prefix is discarded, equality applies.

The actual unchanged Formation.frontier on the all-support table with cap one visits only nine queried digits. Independent geometry shows all 24 can occur under that order, since every full binary assignment has positive probability. The true endpoint fibre is one while the original bound predicate still permits 3^15=14,348,907. This boundary control diagnoses the inference; it does not assert that a particular one of the eleven truncated arithmetic-family rows has a fully recomputed query set. All 32 rows and their eleven censor flags remain preserved. Under the corrected theorem, the twelve rows observing at least 23 digits legitimately imply fibre at most three, and the ten observing all 24 imply singleton fibres, within this declared finite family. No uncapped large frontier is required to retain that useful conclusion.

The separate small actual finite-prefix experiment varies the two queried digits 16 and 23 and obtains seven exact endpoint classes over nine choices, agreeing with the conditional-menu argument. The initial probe accidentally varied only irrelevant digits; it was preserved and replaced with the informative selected-digit experiment. Neither probe is substituted for the proof.

The majority and modified-majority example has total variation one. Its separating event is that all final bits are equal. The original P_T is already a distribution on complete endpoints; access to an event ordering or history is unnecessary to distinguish those two laws. The source's comparison between A(T) and P_T conflates a static set map with a supplied endpoint distribution. The result is valid, but the original complete-records-versus-history headline and the suggested physical dichotomy are not.

## The complete 3,117-witness injectivity certificate

The #7934 sufficient criterion is correct. Let B and B' be distinct legal block sets and choose b∈B'\B, with pair index j. If T has neither bit blocked at j, A_b(j) supplies a realizable mask avoiding B but meeting B'. Otherwise B contains b's partner and the two table digits are opposite deterministic choices. A C_b(j) witness separates in the same direction; if only the partner C condition holds, exchange B and B'. Thus A_0(j), A_1(j) and at least one of C_0(j),C_1(j) for every j suffice for injectivity.

Avoidance is antitone in the blocked set, so it suffices to check maximal choices on the other 23 pairs. Each usable mask covers a Boolean subcube of these deterministic assignments. I independently recomputed all 3,117 actual configuration masks and translated the coverage question into a separate MiniSat countercover encoding. It agrees with the source's from-scratch recursive cover procedure on all 96 requirements: 95 hold, including both A conditions and at least one C condition for every digit. Therefore the finite static map on the 3-torus is injective under the declared definitions. No full enumeration of all table pairs is required.

The one negative is only failure of coverage by the declared pool. C_0(22) was defined in the note using all realizable masks, so a pool failure cannot decide that global statement. The independently reconstructed unserved Boolean block is 80,649,380,013,721. The actual spatial CNF produces configuration `1110..010001......0........` with mask 17,592,320,264,448, serving that block outside the pool. This defeats the offered pool counterexample as a global obstruction. It does not establish global C_0(22); that stronger question remains unresolved. The 95 positive requirements and sufficient injectivity argument need no change.

The six small joint witnesses are also valid configurations. They are conditional probes, however: the displayed mask {0,2,22} is admissible only if d0,d1,d11 are all nonzero in the source's encoding. If known d0=0, every d11 choice produces the same false response. Merely knowing a nuisance digit does not remove its blocking effect. The original guard checks only mask shape and record count and survives this actual adverse case. Unconditional table separation comes from the full covering certificate, whose avoiding witness can depend on the other blocked digits, not from these six masks in isolation.
