## N3 — ADDITIVITY, HONESTLY SPLIT

The parallel lane advertises REFINEMENT ADDITIVITY as one of its verified

### The trace law is NATIVELY additive

For `E_U = sum_{a in U} E_a` the three union effects are ORTHOGONAL PROJECTORS
RESOLVING THE IDENTITY — measured, not assumed: `E_U E_V = 0` for `U != V` and

for every cell of both partitions. **The exact defect vectors are `(0,0,0)` and
`(0,0,0)`.**

This is additive because a union effect is an OPERATOR SUM and the trace is
LINEAR. It is a property of the readout's algebra, it holds for any state and any
partition, and nothing about the fixture is doing the work.

### The determinant law's coarse additivity is a DEFINITIONAL PUSHFORWARD

**THE MACHINERY DEFINES ONLY ATOMIC WEIGHTS.** For a value `a`,
`w(a) = 1 / (det Q(sigma_(2,0) = a) * conj(det Q(sigma_(2,0) = a)))`. There is no
`Q(sigma_(2,0) in U)` anywhere in the committed machinery, hence **NO
INDEPENDENTLY EVALUABLE DIRECT DETERMINANT LAW FOR A VALUE-UNION**. The absence
is MEASURED THREE WAYS by gate E rather than asserted:

1. **A record dictionary maps a cell to ONE SCALAR.** The landed field builder
   reads `records.get((t, x), sigma)` and sympifies the result into the cell's
   shear slot. Its own source is read by the gate.
2. **Multiple values at one dictionary key is not a valid pin.** Writing two
   values at the same key collapses to one — measured: the two-entry literal has
   length 1 and retains only the later value. A pin that silently discards half
   its content is not a pin of a union.
3. **Choosing a representative is not a union**, and handing the cell a SET
   rather than a scalar does not build one either: the set sympifies to a
   `FiniteSet`, which is not a number, so it is not a shear value and no
   `Q(sigma in U)` is thereby formed.

**THE NATURAL EXTENSION IS A PUSHFORWARD.** Define `w(U) = sum_{a in U} w(a)` and
`p(U) = w(U) / sum_{V in P} w(V)`. On both `P1` and `P2` this induced coarse law
equals `sum_{a in U} p_det(a)` exactly; **the defect vectors are `(0,0,0)` and
`(0,0,0)`.**

**AND THAT IS ADDITIVE BY DEFINITION OF THE PUSHFORWARD AND IS NOT A NEW CLOSURE

extended to a partition by summing its atoms is additive on that partition, for
any atoms whatsoever. **IT DOES NOT SHOW ACTION-LEVEL MERGE CLOSURE**, because
there is no action-level object being merged — no `Q` is built for a union and no
determinant of a union is taken.
