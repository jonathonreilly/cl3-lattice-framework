## Result up front

The first information-disposition obstruction was narrower than it appeared. Replacing
the arbitrary quantum contents of blank Record targets by fixed labels is
many-to-one unless those contents leave through a return port. But a realized
five-M2 branch already contains three basis possibilities

```text
(P,M,B) = (1,m,b),       m in {0,1}, b in {0,1}.
```

They can serve as candidate Record contents. First apply the fixed
one-M2 gate `H` to the known `P=1` factor, producing the marker
`|->=(|0>-|1>)/sqrt(2)`. A finite nearest-neighbour permutation then routes
`P,M,B` to three initially arbitrary, Record-free targets. The previous target
contents and every other background possibility are displaced bijectively
rather than reset. The resulting exact local projectors are

```text
head = |-><-|,       root = |m><m|,       metadata = |b><b|.
```

The three sites form a connected right-angle packet. The root is its unique
degree-two site; the non-basis head marker distinguishes the two endpoints.
Thus the post-Record configuration alone recovers

```text
s = 2m - 1,        h = m + b,
old source = root, new source = head.
```

If an Admissibility rule supports those contents and a simultaneous
three-site formation rule is separately supplied, those are the matrices the
Records could lock without replacement. The runner does not supply either
law.

This changes the earlier non-Hermitian two-Record parser. It is a positive
same-carrier alternative, not a proof that the earlier parser is impossible.
It removes the need for a fresh Record qubit, target erasure, an environment
sink, or a metadata calibration on this finite domain.
