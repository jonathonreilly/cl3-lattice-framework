The recovered finite fixture supplies a positive Gaussian form

\[
A_a(\phi,\zeta)
=c^{-1}\lVert q_a\phi-B_a\zeta\rVert^2+\lVert\zeta\rVert^2,

whose covariance and determinant-derived arm ratios equal the supplied finite
target values, but its residual

This block now supplies a concrete finite construction on two explicitly
different mass-one backgrounds at `T_cover=12`: the xgraded background
at width four and the constant background at width eight. It names every
scalar variable, assigns it an actual site in `Z^3` and a payload slot, and
replaces every routed nonzero cross-site precision edge by an explicit chain
of nearest-neighbor unit-pivot mediators. Exact compiler and Record Schur

That is meaningful progress: there is no scalar-algebra, Record-star-capacity

It is not the fixed-density theorem we need for physical locality. The explicit

an arbitrary lattice with a constant amount of carrier hardware per physical
site. Because the two widths use different backgrounds, they are two disclosed
fixtures and not a same-background scaling ladder.

## The exact algebra

The fixed normalized complex-Gaussian split is

\[
{C\over\pi}\int_{\mathbb C}
e^{-\alpha|u-y|^2-\beta|v+y|^2}\,d^2y
=e^{-|u+v|^2},
\]

with

\[
\alpha=3,\qquad \beta={3\over2},\qquad C={9\over2},
\qquad {\alpha\beta\over C}=1.
\]

Recursive application reduces the worst eleven-coordinate residual to
arity-at-most-three factors while isolating original occurrences at leaves.
Zero coefficients keep the same normalized mediator roster, so no arm receives
a hidden normalization advantage.

Every supplied residual row is first scaled by `1/sqrt(c)`. This is essential: the
target is `c^-1 ||q phi-B zeta||^2`, not the unscaled residual square. Both the
supporting runner and the explicit certificate use that scale in the Record
decomposition. This block executes `m=1` only, hence `c=1/2` and `c=1/3`;
no wider positive-mass statement is promoted into this certificate.

The three arm-sensitive rows are decomposed into an arm-blind part and a
Record-centered bridge. Their changing data pack exactly as

\[
|S0|=4,\qquad |S1|=3,\qquad |S2|=2.
\]

The bridge pivot is one, the normalized Gaussian pivot is `C`, and reverse
elimination reconstructs every arm exactly for both splits.

## The explicit finite site and slot map

For every factor, the runner forms its sparse Hermitian scalar precision graph.
Every visible or compiler variable gets a home site. Every routed nonzero
cross-site edge gets a distinct terminal port. A deterministic Manhattan path
then:

1. exits the left home through its assigned port;
2. climbs to the edge's private `z` layer;
3. crosses horizontally without sharing another edge's layer;
4. descends through the assigned right port.

Every consecutive site pair is checked to have Manhattan distance one. Every
internal route site is checked against home sites and against its local
three-payload occupancy. One generic unit-pivot Schur calculation restores an
arbitrary Hermitian edge, including a zero coefficient; finite induction then
applies that identity along each displayed path. The runner does not directly
form or eliminate the complete routed precision matrix.

Ordinary active carriers reserve the identity coefficient for an integer
frame/role code and use at most the three Pauli coefficients as payloads. The
Record center uses the same tag-plus-three-payload form. `S0` is the declared
exception: it uses all four complex `M_2(C)` coordinates as payloads. Every
route incident on S0 is checked to begin at an adjacent carrier, but the code
does not instantiate or verify a tag role that selects the corresponding S0
payload slot. The integer role codes are also not reduced to a
cover-independent finite type set. These open metadata conditions are reasons
full-map cubic covariance remains open.
