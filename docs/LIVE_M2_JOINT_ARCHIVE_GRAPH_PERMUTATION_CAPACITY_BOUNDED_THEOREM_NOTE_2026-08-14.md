## Exact Graph-Permutation Lemma

Let the six intended archive arrows be

```text
s_i -> t_i,  i=1,...,6,
```

with all `s_i` distinct and all `t_i` distinct. Form the directed graph on
`S union T` with those six edges. Every vertex has indegree at most one and
outdegree at most one. Consequently, each weak component is either:

- a directed path `v_0 -> v_1 -> ... -> v_k`; or
- a directed cycle `v_0 -> ... -> v_(k-1) -> v_0`.

For a path, close the content flow by sending the displaced content of `v_k`
back to `v_0`. The content cycle is implemented by the reversed adjacent
transpositions

```text
(v_(k-1),v_k), ..., (v_1,v_2), (v_0,v_1).
```

The same transposition word implements an already closed cycle. Direct
symbolic simulation starts with a distinct token at every vertex and verifies

```text
final_content[t_i] = initial_content[s_i]
```

for all six arrows. The final token multiset equals the initial token multiset,
so the map is bijective and preserves every displaced prestate.

The component enumerator explicitly skips path starts already consumed by a
previous component. This matters: an earlier scratch prototype double-counted
a vertex in a length-three path. The frozen runner reconstructs the original
edge set from the components and asserts exact one-component membership before
giving any coverage credit.

## Sharp Duplicate-Source Capacity Count

- `u` be the number of distinct branch-source factors;
- `T` be the six distinct Record targets;
- `q = |S intersect T|`;
- all `u` source values be fixed after conditioning on a compatible joint
  branch;
- every target not already a source carry an arbitrary prestate that must be
  preserved;
- all six target factors be exact locks after the archive.

On the source-target union, the input branch subspace has dimension

```text
2^(6-q),
```

because `6-q` targets are not fixed sources. After locking all six targets,
only `u-q` factors in the union remain free, so the output capacity is

```text
2^(u-q).
```

An isometry requires `2^(6-q) <= 2^(u-q)`, equivalently `u >= 6`. When
`u<6`, the exact clean-factor deficit is therefore

6-u.
