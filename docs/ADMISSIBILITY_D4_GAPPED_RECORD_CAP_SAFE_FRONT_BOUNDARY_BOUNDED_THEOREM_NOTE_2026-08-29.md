## 2. Exact geometric mechanism

Let the permanent-Record set initially be

```text
R(f,L) = {-2f} union {0,f,2f,...,(L-1)f},    L >= 2.
```

For an empty candidate `x`, the frozen predicate requires exactly one nearest
Record `p`, infers `d=x-p`, requires another Record at `x-2d`, and requires the
other five nearest neighbors to be empty.

There is a short graph proof.  The trail Records form one adjacency path and
the cap is isolated.  Every eligible candidate must extrapolate a directed
adjacent Record edge.  The only empty extrapolations of the trail path are
`-f` and `Lf`.  Candidate `-f` has two nearest Records, at `-2f` and `0`, so it
fails the unique-neighbor test.  Candidate `Lf` has the unique predecessor
`(L-1)f` and grand-predecessor `(L-2)f`, so it passes.  A lateral neighbor of
the cap has no collinear grand-predecessor, and `-3f` likewise lacks one at
`-f`.

Proper cubic rotations and translations preserve adjacency, the empty gap,
and the relation `cap=-2f`.  Hence

```text
E(QR+t) = {(Qx+t,Qd) : (x,d) in E(R)}.
```

and 42 translated cases in exact integer geometry.

## 7. Why the cap is supplied

The input state already distinguishes `f` from `-f`: the isolated cap marks
the rear endpoint at distance two.  Nothing in the current event creates that
marker.  This is the literal meaning of `supplied_cap: true` and
`generated_cap: false`; it is not an impossibility statement.

There is one narrow symmetry observation.  A deterministic equivariant map
from an exactly cubic-invariant precursor to one nonzero signed axis cannot
exist, because the output would have to be fixed by every proper cubic
rotation.  This does not block stochastic symmetry breaking.  A covariant
instrument may produce six equiprobable signed-axis branches, or a 24-branch
frame orbit, and let the realized Record branch carry the arrow.

That writer must create the cap and the live packet together without receiving
`f`, a chosen site, role, epoch, tape, or scheduler.  If it succeeds, the
supplied-boundary import can be tested for retirement.  If it fails, the exact
failure—not the present positive—will determine whether the residual belongs
to dynamics, boundary conditions, or the axioms.
