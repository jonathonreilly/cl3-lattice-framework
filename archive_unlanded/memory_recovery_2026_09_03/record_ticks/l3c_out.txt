
############################################################################################################
SECTION 0  the declared model
############################################################################################################
cluster            : 2x2x2 cube, 8 corners, 12 edge sites -> 12 qubits, dim 4096 (BKSF, L3/L3b verified)
stabilizers        : 5 independent face operators; code space 2^7 = 128
state space used   : the N=2 record sector = span{|z> : corner-parity pattern has weight 2}, dim 896 = 28 x 32.
                     every hop term preserves it exactly, so nothing above 896x896 is ever formed.
pre-record H       : H = sum_edges T_e, T_e = (i/2) A_e (B_i - B_j); code-sector spectrum {-4,-2,0,2,4},
                     ground level -4.  On the whole 896-dim sector (32 flux copies) the extreme level is -(2+2sqrt2).
TICK               : (i) every unrecorded edge site forms a record with probability p, independently;
                         each locks a value with the odds carried by the current state (Lueders conditioning,
                         sequential in a random order inside the tick);
                     (ii) the pre-record state then evolves by exp(-i tau H_R).
MODEL CHOICE A     : H_R = sum of hop terms on UNRECORDED sites (exactly the terms commuting with every
                     registered Z_e, since T_e is the only term with X support on site e).  Primary model.
MODEL CHOICE B     : keep the full H each step and re-condition on the registered values afterwards. Tested.
clock              : site e's formation tick is Geometric(p); the finished set is complete at tick max_e T_e.
dictionary         : the finished set of 12 locked values fixes one of the 28 corner pairs (vertex pattern).

SECTION 3  the three regimes
############################################################################################################
(i)  fast-formation limit p -> 1 : the finished set is the Born diagonal of the initial state (Section 1).

(ii) slow-formation limit p -> 0 at fixed tau.  The gap before each record diverges, so the pre-record
     state fully dephases in the energy basis of the CURRENT H_R, and records form one at a time in a
     uniformly random site order.  That limiting process is simulated exactly (random-phase unravelling
     of  rho -> sum_E P_E rho P_E  at every gap).
